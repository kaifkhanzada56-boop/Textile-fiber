🧵 Textile Fibers Explorer

Textile Fibers Explorer is a Streamlit-based web application designed for textile engineering students to learn, explore, compare, and select different textile fibers.

📌 Features

* 🔎 Fiber Explorer – Explore detailed information about individual textile fibers.
* ⚖️ Compare Fibers – Compare 2 or 3 fibers side by side.
* 🎯 Fiber Selection Tool – Select suitable fibers according to their properties and applications.
* 📚 Reference Table – Search and filter textile fibers easily.
* 🧵 Information about natural, regenerated, and synthetic fibers.

🧶 Fibers Included

The application currently contains information about:

* Cotton
* Wool
* Silk
* Linen
* Viscose
* Polyester
* Nylon
* Acrylic
* Spandex
* Hemp

📊 Fiber Information

For each fiber, the application provides:

* Fiber category
* Source
* Chemical composition
* Strength
* Moisture absorption
* Feel
* Advantages
* Disadvantages
* Common applications

🚀 Installation

First, clone the GitHub repository:

git clone https://github.com/YOUR-USERNAME/textile-fibers-streamlit.git

Move into the project folder:

cd textile-fibers-streamlit

Install the required libraries:

pip install -r requirements.txt

▶️ Run the Application

Run the following command:

streamlit run app.py

The application will open automatically in your web browser.

🌐 Deploy on Streamlit Community Cloud

1. Upload app.py, requirements.txt, and README.md to GitHub.
2. Open Streamlit Community Cloud.
3. Sign in using your GitHub account.
4. Select Create App.
5. Select your GitHub repository.
6. Select the main branch.
7. Select app.py as the main file.
8. Click Deploy.

Your Textile Fibers application will then be available online.
